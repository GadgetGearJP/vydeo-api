外部ダウンロードAPIの設定（任意）

APIが未設定の場合、通常の動画ページURLの解析はできません。サーバーはHTTPSとCORSに対応する必要があります。

API の仕様・注意事項を開く

POST /api/info に {"url":"..."} を送信し、{"title":"...","thumbnail":"...","formats":[{"label":"1080p MP4","url":"https://..."}]} を返す構成です。GET で映像を配信するダウンロードURLが必要です。第三者による悪用を防ぐため、APIに認証・URL制限・レート制限を実装してください。

ブラウザの仕様や配信元の制限により、ダウンロードリンクを押すと再生画面が開く場合があります。全サイトへの対応や最高画質の保証はありません。
